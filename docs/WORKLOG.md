## Формат записи

- Дата и краткое название.
- Тип: разработка / исследование / решение пользователя / методика / порядок / проверка / блокер / отмена.
- Задачи: ID из COOP-STATUS или общие правила.
- Основание и цель: требование, наблюдение, фактические источники.
- Сделано: изменения, решения, существенные компромиссы, что заменено/отменено.
- Проверки: SHA/run/артефакт/сценарий, реальный результат и непроверенное.
- Следующий шаг, блокеры, необходимые решения.
- Ревизия: проверенный base SHA и связанные commit/PR. SHA собственного коммита при необходимости уточнить позднее.
