# Dialogue02 для Skyrim SE 1.6.1170

Один архив MO2 содержит клиент, сервер и изменения Dialogue01. Изменился формат пакетов диалога и результатов попаданий. Обоим игрокам и серверу нужна одна версия.

| Что изменилось | Как работает |
|---|---|
| Облачко разговора | Обновление игры находит локальные объекты NPC и говорящего сопартийца. На каждом кадре отрисовки клиент заново проецирует их положения через текущую камеру Skyrim. Для обычных разговоров достаточно сетевого сообщения о начале и редких обновлений. |
| Выноски | Пока оба персонажа загружены и попадают в кадр, от облачка идут две линии. Если виден один, линия идёт только к нему. Когда оба за краем экрана, остаются облачко и усиленная стрелка. Проверяется попадание в кадр. Проверки перекрытия стеной или другим предметом в этом варианте нет. |
| Размер и положение | При высоте экрана 720 пикселей ширина облачка составляет 44 пикселя, прежнего значка при стандартном шрифте — 32 пикселя. Размер адаптируется к разрешению. По умолчанию верхний отступ панели группы составляет 30% высоты, у выбранной строки игрока правый отступ составляет 16% ширины. Другие заданные пользователем позиции панели сохраняются. У старого верхнего отступа 3% тот же вид, что и у прежнего значения по умолчанию, поэтому он тоже переходит на 30%. |
| Несмертельный удар | Клиент, ударивший чужую сетевую копию NPC, учитывает результат обработки удара движком. Если NPC выжил, по сети передаётся фактически снятое здоровье с признаком несмертельного удара. Различие в здоровье между компьютерами само по себе теперь не делает такой удар смертельным. Другая ветка обработки на стороне зрителя больше не возвращает расчётный признак убийства при воспроизведении чужого удара по NPC. |
| Выигрыш драки | В этой версии награду выдаёт действующий игровой скрипт. Для общего исхода нужна запись участников при принятии вызова, отдельное подтверждение победы и квитанция на каждого получателя. Оба участника совместного диалога должны получить предусмотренную награду один раз. Право наёмника следовать за каждым игроком проверяется отдельно согласно требованиям кампании. |
| Камера и сохранение | Управление камерой и передвижением, совместный зачёт результатов и резервная копия кампании остаются отдельными задачами интеграции. |

Для проверки интерфейса достаточно одного разговора. Поворот камеры проверяет положение маркера, выход одного собеседника за край кадра проверяет выбор выносок. Вблизи новая реплика появляется справа и затухает. Состояние уже погибшего или застрявшего в позе NPC в старом сохранении отдельно от нового несмертельного удара.

Проверки исходников охватывают 120 последовательных положений камеры, обе видимые цели, одну цель, обе цели вне кадра, незагруженную цель, три формата экрана и сохранение номера сетевой сущности при сериализации. Отдельно исполняются обработчики урона со смоделированным движком. Охвачены смертельные и несмертельные удары, разные начальные запасы здоровья, повтор несмертельного сообщения и устаревшие данные при смене владельца NPC. Chromium открыл интерфейс из установочного архива и подтвердил отступы, размер реплики, затухание, удаление текста и передачу лидерства. Код отрисовки дополнительно проверен на 120 последовательных положениях камеры с записью вызовов рисования. Реальные FPS, завершение квеста, озвучка и поза Утгерд требуют двух работающих клиентов Skyrim.
