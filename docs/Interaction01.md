# Совместный диалог и стандартные спутники

Сборка для Skyrim SE 1.6.1170. В строке версии клиента и сервера указан суффикс `-coop-interaction1`. На обоих ПК установите один архив в MO2, отключите Dialogue02 и запустите сервер из новой версии. Для второго ПК в архиве есть копия клиента под именем `SkyrimSE.exe`.

| Действие | Что делает сборка |
|---|---|
| Член группы начал разговор | У другого игрока появляется маркер. Если подойти, навести прицел на NPC или говорящего и нажать «Присоединиться», сервер проверяет расстояние, группу и текущий разговор. Камера наблюдателя включается после подтверждения. Backspace возвращает управление. |
| Говорящий выбрал ответ | Сообщение содержит говорящего, номер разговора, номер выбора и запись INFO с учётом порядка загрузки. Наблюдатель видит текст. Звук NPC воспроизводит существующий канал STR. |
| Реплика изменила этап своего квеста | Для собственных квестов реплики типов None и Misc сервер распознаёт реальное изменение этапа в течение восьми секунд. При выключенной общей экспериментальной синхронизации побочных квестов такое изменение получает только состав слушателей на момент выбора. Другие квесты продолжают использовать обычную синхронизацию STR. |
| Изменилось отношение NPC | Если у NPC во время разговора вырос ранг отношений с говорящим до дружеского или выше, сервер передаёт его записавшимся участникам. Более высокий личный ранг сохраняется. |
| Началась стандартная кулачная драка | Клиент узнаёт фактического противника по роли в квесте DGIntimidateQuest. Сервер отдаёт симуляцию NPC вызывающему игроку, когда оба в зоне симуляции. Поблизости передаются наблюдения о том, что противник жив или стоит на колене. Для следующего инициированного игрой разговора с этим NPC сервер может подключить ближайших участников предыдущего разговора. |
| Игрок нанимает стандартного спутника | Сервер резервирует конкретного NPC, клиент сверяет тот же открытый разговор и выбранную реплику. Оригинальную команду исполняет клиент нанимателя. Освобождение штатной роли спутника снимает закрепление. Движением закреплённого NPC в зоне симуляции управляет клиент владельца. |
| Разговор с чужим спутником | При проверке стандартных условий реплик Skyrim видит чужого спутника доступным для разговора и занятым для найма. Штатный ответ об отсутствии места выбирается из установленных файлов игры. Два одновременных запроса на свободного NPC разрешает сервер. |
| Поездка на обычной повозке | Близкому члену группы приходит приглашение. При согласии сервер отправляет пассажира к месту прибытия извозчика. |
| Хранение этапов квестов | Сервер пишет принятые события в `config/CoopJournal`. Клиент запрашивает недостающие записи и сохраняет их в `%LOCALAPPDATA%\SkyrimTogetherReborn\CoopJournal`. Новая группа создаёт отдельный журнал. |

Проверки в репозитории исполняют обработчики клиента и сервера с заменами игровых объектов, проверяют сериализацию сообщений, запись журнала и интерфейс из собранного архива. Воспроизведение озвучки, фактический ракурс камеры, выход из физики падения и поведение модифицированных NPC требуют проверки внутри Skyrim.

Для полноценной кампании остаются открытыми вопросы сохранения и сверки операций с золотом и предметами, переноса произвольных эффектов Papyrus, поддержки альтернативных систем спутников, совместного обмена предметами и путешествий из сценариев отдельных квестов. Сохранения персонажей и журнал этапов содержат разные данные. Журнал сам по себе не восстанавливает инвентарь и личные переменные скриптов.
