## История предыдущих сборок

## Dialogue02

Установочный архив для обоих клиентов и сервера — `Skyrim-Coop-SE-1170-Dialogue02-MO2.zip`. Облачко диалога привязано к двум собеседникам и отрисовывается в кадре Skyrim. Увеличены стрелка и текст ответа, панель группы перемещена ниже. При обработке удара по NPC учитывается его несмертельный исход на компьютере ударившего. Для Утгерд сохраняется открытая игровая проверка. [Изменения и границы версии](docs/Dialogue02-RU.md).

Windows x64 прошла 91 проверку в 10 тестах. Тест в Chromium подтвердил перенос панели группы со старого отступа 3% на 30%, положение, размер и затухание реплики, а также передачу лидерства. В архиве для MO2 проверены клиент, копия лаунчера для второго ПК и сервер. SHA-256 установочного архива с файлами лицензий — `7c2df8fbfcb09e0be62d217c3430c0ab202cc2a14a8fa0a5209177fccc376b06`. [Сборка и проверка упакованного интерфейса](https://github.com/Mobelon6/skyrim-together/actions/runs/44949202887).

## Dialogue01

Предыдущая установочная версия — `Skyrim-Coop-SE-1170-Dialogue01-MO2.zip` для обоих клиентов и сервера. Она включает накопленные изменения State03, передачу лидерства в окне группы и отображение разговора сопартийца на экране. Один из игроков может начать разговор, другой видит направление и прочитывает выбранную реплику вблизи. Камера наблюдателя, выдача квестовых последствий и резервная копия мира пока описаны и моделируются отдельно. [Спецификация и состояние реализации](docs/Party-Dialogue-and-Recovery-RU.md).

Windows x64 прошла 91 проверку в 10 тестах. На интерфейсе из того же архива отдельно проверены маркер, замена реплик, затухание и кнопка передачи лидерства. Двухклиентская игровая сессия для этой версии пока не проверена. [Windows-сборка](https://github.com/Mobelon6/skyrim-together/actions/runs/44922630682) · [Проверка интерфейса](https://github.com/Mobelon6/skyrim-together/actions/runs/44946213293).

SHA-256 установочного ZIP с включёнными файлами лицензий — `10577db801959263ffd26ceb0cd8b325260217badce97e64e8e05519cbe19b60`. Клиент, сервер и интерфейс в точности соответствуют архиву Windows-сборки.

## Сборка 03

Клиент, сервер и интерфейс собраны на Windows x64. TPTests прошёл 85 проверок в 9 тестах. Сервер успешно создал конфигурационный файл. В комплект входят два идентичных клиентских EXE для обычного запуска и для профиля с переименованным лаунчером. [Журнал сборки](https://github.com/Mobelon6/skyrim-together/actions/runs/44893833022)

Итоговый файл для MO2 — `Skyrim-Coop-SE-1170-State03-MO2.zip`. SHA-256 — `543c35a666258f25a12607b35274bae03fb4ff59c2c04ea82e7b5011dde533a1`. За основу взят архив сборки по ссылке выше. В итоговом ZIP добавлены лицензии и заменён только `TPProcess.exe` на ранее собранный исправленный вариант. Двоичная библиотека CEF в точности совпала с той, для которой был скомпилирован этот компонент. Обновлённый сценарий автоматической сборки включает ту же правку оверлея в исходном виде. Проверка с двумя игровыми клиентами остаётся открытой.
